========================================================================
             RBSK SCREENING HEALTH - 1-CLICK INSTALLATION & LAUNCH
========================================================================

HOW TO INSTALL AND RUN:

1. Double-click "ONE_CLICK_INSTALL_AND_RUN.bat" (or "SETUP_RBSK.bat")
   
   What this will do automatically:
   - Check if Python is installed on your PC. If not, it will silently 
     install Python 3.12 automatically without asking any manual steps.
   - Install Selenium, Cryptography, OpenPyXL, Requests, and Urllib3.
   - Create a Desktop shortcut titled "RBSK Screening".
   - Automatically launch the RBSK Screening Application.

2. FUTURE LAUNCHES:
   - Double-click the "RBSK Screening" icon on your Desktop.
   - OR double-click "OPEN_RBSK_SCREENING_APP.bat".

========================================================================
Included Files:
- ONE_CLICK_INSTALL_AND_RUN.bat : Master 1-Click setup & app launcher.
- SETUP_RBSK.bat               : Automated environment setup script.
- OPEN_RBSK_SCREENING_APP.bat   : Direct app launcher.
- python_installer/             : Standalone Python 3.12 installer.
- wheels/                       : Offline Python packages (Selenium, etc.).
